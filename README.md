# Job Resume Tailor — GitHub Pages site

## Publish
1. Create a **public** repository named `job-resume-tailor-site` under `Adarsh-Talla`.
2. Upload all files in this folder to the repository root (not the ZIP itself).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then Save.
6. Wait for the Pages deployment to finish. Your site should be:
   https://adarsh-talla.github.io/job-resume-tailor-site/
